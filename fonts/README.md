# Map fonts

Glyph files (MapLibre "glyphs") for the B'Tselem maps' text: Noto Sans
Regular, only the Unicode ranges the maps use (Latin, Hebrew, Arabic and its
presentation forms, punctuation, dingbats). Served by GitHub Pages at
`https://projects.btselem.org/main-map-geojson/fonts/{fontstack}/{range}.pbf`.

Taken from [protomaps/basemaps-assets](https://github.com/protomaps/basemaps-assets).
Noto Sans is © Google and licensed under the SIL Open Font License 1.1.
A label with a character outside these ranges misses that character: add its
range file from the same source.
